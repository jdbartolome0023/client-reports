ReadThis gap widened this period, reversing the trend from the last few reports, but it's now mostly explained. Real revenue fell to 30.7% of platform-reported (from 73.9% last comparison), and the overstatement multiple more than doubled, from 1.35× to 3.26×. This is not the same fixable UTM-tagging issue flagged in earlier reports (that fix is still in place and working: the resolution rate on named categories actually improved this period, see below). Investigated this period: most of the drop traces to an unusual demand spike in the Jul 1-9 comparison baseline itself (Jul 8-9 alone carried roughly half that window's orders, consistent with a heating-oil bulk-fill pattern), not a genuine August collapse. A real but moderate decline of roughly 40% remains in the Google-tagged channel once the spike is adjusted for, see Recommendations.
What's not the causeNot a measurement-quality problem this time. Only 12.5% of this period's Google-tagged orders had a blank Product field (vs. 66% last comparison) - the resolution rate genuinely improved. The gap widened because the underlying real order volume dropped, not because more orders became unclassifiable.

Methodology & caveats

  • Real revenue basis: WooCommerce "Net Sales" column (ex-VAT, ex-shipping), 90 valid orders Aug 1–9, 167 Jul 1–9 (refunded orders excluded from both counts). Both periods verified to cover exactly 9 calendar days with no gaps.
  • Channel attribution: orders tagged exactly "Source: Google" counted as Google-verified. "Organic: Google" (unpaid search) is never summed into this total, under any framing, since organic traffic has nothing to do with Google Ads spend.
  • Standing exclusion: Compost, Sand+Stones, and Coal/solid fuel revenue tagged "Source: Google" is excluded from Google's real-revenue total: no Google Ads campaign targets any of these categories, so this is confirmed misattribution.
  • This period's gap is a volume story, not a tagging story: the Jul 8 UTM/auto-tagging fix remains in place and working (resolution rate on named categories actually improved this period). The widened multiple reflects fewer real orders, not a fix regressing.
  • Kenergy Solar: excluded from all real-profit math and every Google real-vs-platform ratio. It's a quote-based install service, not a WooCommerce checkout product, so it has zero orders to verify against. Its €12,000-per-conversion value is a manual ADD rule, Ciaran-confirmed but never checked against a real closed deal.
  • Live platform data: pulled fresh via Google Ads' own reporting API (GAQL) for the exact Aug 1–9 / Jul 1–9 windows.
